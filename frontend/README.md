# CalmSense Dashboard

React and TypeScript dashboard for the CalmSense stress-detection project. It renders the
committed experiment output, so it works on static hosting with no backend. All reported
numbers come from `src/data/results.json`, generated by the experiment scripts.

Live demo: https://urmeo.github.io/CalmSense/

## Pages

- Dashboard: headline LOSO results and the within- vs. subject-independent optimism gap
- Signal Explorer: real WESAD chest signals across baseline, stress, and amusement
- Explainability: global mean absolute SHAP feature importance and the motion-confound note
- Model Comparison: per-model accuracy, wrist-only, and cross-dataset results

## Development

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build (also run in CI deploy)
```

## Regenerating dashboard assets

Run this from the repository root after retraining the model:

```bash
python scripts/build_dashboard_data.py  # frontend/src/data/results.json
python scripts/export_signals.py        # frontend/src/data/signals.json
```
